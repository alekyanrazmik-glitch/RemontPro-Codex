# RemontPro — сайт-платформа ремонта

Статический сайт для GitHub Pages: публичная часть читает портфолио и видео из JSON, а демо-админка в `/admin/` хранит изменения в `localStorage` и экспортирует готовые `projects.json` / `videos.json`.

## 1. Как заменить телефон

В проекте используется заглушка `PHONE_PLACEHOLDER`.

1. Найдите все вхождения `PHONE_PLACEHOLDER`.
2. Замените на номер для `tel:` и WhatsApp в международном формате без плюса, например `79990000000`.
3. Проверьте ссылки `tel:79990000000` и `https://wa.me/79990000000`.

## 2. Как заменить адрес сайта

В SEO, `sitemap.xml` и `robots.txt` используется `SITE_URL_PLACEHOLDER`.

1. Замените заглушку на адрес без завершающего слеша.
2. Для GitHub Pages: `https://username.github.io/repo-name`.
3. Для домена: `https://example.ru`.

## 3. Как добавить проект через админку

1. Опубликуйте сайт или запустите локальный сервер: `python3 -m http.server 8010`.
2. Откройте `/admin/project-edit.html`.
3. Заполните ID, название, город, площадь, тип ремонта, срок, бюджет, описание, главное изображение, галерею и YouTube-ссылку.
4. Для галереи укажите по одной ссылке на изображение в строке.
5. Нажмите **Сохранить**. Проект сохранится в `localStorage` браузера.

## 4. Как экспортировать JSON

1. Откройте `/admin/` или `/admin/portfolio.html`.
2. Нажмите **Экспорт projects.json**.
3. Для видео откройте `/admin/videos.html` и нажмите **Экспорт videos.json**.
4. Скачанные файлы можно положить в `assets/data/`.

## 5. Как заменить `projects.json`

1. Скачайте JSON из админки.
2. Замените файл `assets/data/projects.json` в репозитории.
3. Закоммитьте изменение и дождитесь деплоя GitHub Pages.

## 6. Как добавить YouTube-видео

1. Откройте `/admin/videos.html`.
2. Укажите название, категорию, описание, preview и ссылку YouTube.
3. Поддерживаются ссылки `youtube.com/watch?v=...` и `youtu.be/...`.
4. Экспортируйте `videos.json` и замените `assets/data/videos.json`.

## 7. Как подключить настоящий backend позже

Текущая админка — демонстрационная и не защищена: она работает только с `localStorage`. Для production-админки нужен backend или headless CMS:

- Strapi, Directus, Sanity, WordPress Headless или собственный API;
- авторизация администратора;
- загрузка файлов на сервер/S3/CDN;
- API для проектов и видео вместо ручной замены JSON;
- роли, резервные копии и аудит изменений.

Публичный JS уже отделён от данных: вместо `fetch('assets/data/projects.json')` можно подключить API endpoint.
