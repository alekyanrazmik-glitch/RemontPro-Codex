# RemontPro — статический сайт для GitHub Pages

Многостраничный сайт компании RemontPro для заявок на ремонт квартир, домов и коммерческих помещений в Геленджике и Новороссийске.

## Структура

- `index.html` — главная страница.
- `uslugi/` — услуги ремонта.
- `goroda/gelendzhik/` и `goroda/novorossiysk/` — городские посадочные страницы.
- `portfolio/` — карточки проектов.
- `prices/` — подробная таблица цен.
- `blog/` — список статей.
- `faq/` — FAQ-аккордеоны.
- `contacts/` — контакты и форма заявки.
- `assets/css/style.css` — стили сайта.
- `assets/js/main.js` — мобильное меню, FAQ и обработка формы.
- `sitemap.xml` и `robots.txt` — файлы для индексации.

## Как заменить телефон

В проекте используется единая заглушка `PLACEHOLDER_PHONE`.

1. Откройте поиск по проекту.
2. Замените все вхождения `PLACEHOLDER_PHONE` на номер в международном формате без плюса и пробелов для WhatsApp, например `79990000000`.
3. Для ссылок `tel:` можно использовать тот же формат: `tel:79990000000`.
4. Проверьте, что ссылки вида `https://wa.me/79990000000?...` открывают WhatsApp.

## Как заменить SITE_URL_PLACEHOLDER

В SEO-мета, `sitemap.xml` и `robots.txt` используется заглушка `SITE_URL_PLACEHOLDER`.

1. Замените `SITE_URL_PLACEHOLDER` на адрес сайта без завершающего слеша.
2. Для GitHub Pages это может быть `https://username.github.io/repository-name`.
3. Для будущего домена это может быть `https://remontpro.ru`.
4. После замены проверьте `sitemap.xml` и `robots.txt`.

## Как включить GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. В поле **Branch** выберите ветку с сайтом и папку `/root`.
5. Нажмите **Save**.
6. Дождитесь публикации и откройте адрес, который GitHub покажет в разделе Pages.

## Локальная проверка

```bash
python3 -m http.server 8010
```

После запуска откройте `http://127.0.0.1:8010/` и проверьте:

- мобильное меню;
- раскрытие FAQ;
- отправку формы в WhatsApp;
- переходы по внутренним ссылкам.
